## 2. 现状关联关系（阶段 01 ER 文字版）

| 父 | 子 | 关联字段 | 约束现状 |
|---|---|---|---|
| `users` | `user_profiles` / `user_extended` / `user_preferences` / `voice_preferences` | `user_id` | 外键 / 唯一（见说明文档 §4.3） |
| `users` | `auth_sessions` | `user_id` | 外键；只存 token 哈希 |
| `users` | `family_members` | `user_id` | `fk_family_members_user` + `uq_family_members_idem(user_id, idempotency_key)` |
| `users` | `health_records` | `user_id` | `fk_health_records_user`；索引 `idx_health_records_user(user_id)`、`uq_health_records_idem(user_id, idempotency_key)` |
| `family_members` | `health_records` | `family_member_id` | **仅逻辑引用，无外键**；现有 7 条全部为 NULL |
| `health_records` | `health_record_attachments` | `record_id` | `fk_hr_attach_record`（CASCADE） |
| `users` | `health_record_attachments` | `user_id` | `fk_hr_attach_user`（NO ACTION）；另有 `idx_hr_attach_user` |
| `departments` | `doctors` / `appointments` | `department_id` | 外键；`departments.hospital_id` 为字符串、无机构表外键 |
| `health_records` | `ai_tasks` / `care_plan_requests` | `record_id`（解读任务） | 逻辑引用，见说明文档 §6.2 |

**当前报告数据模型**：`health_records.summary` 单段文本承载全部检查结论；无项目级结构化字段；附件表空。→ 与「专业电子检查报告」的差距判断**成立**。
