## B. 页面布局调整方案

### B-1 首页：把「描述症状」做成唯一主操作，其余降为导航

模块顺序（自上而下，单列）：

```
[原生导航]  #EAF3FF 底 + 黑字（与 hero 同色，视觉上"消失"）
┌ hero ──────────────────────────────── 约 385rpx（现 ≈470）
│ 品牌行：logo 56 · AI 健康助手 30/700 · 让就医更简单 22
│                                    小安 120（现 150，去掉箭头）
│ 问候：36/700
│ 副行：26/400 --text-sub（"晚上好"）
│ ┌ 主操作卡 ─────────────────────── 112rpx，圆角 24，白底+投影
│ │ mic 56 ｜ 请用一句话描述您的症状… 26 ｜ 发送 72 圆
│ └
│ 快选词：**换行两行**（不再横滑），chip 高 64
└
四宫格  约 157rpx（现 ≈220）：tile 72 → 标题 24/600，**删掉 desc 视觉层**
导诊说明条（原 banner）152rpx：标题 28/700 + 说明 22，**无按钮、无手写标注、无旋转**
常用服务 card：icon 72 · 名称 24 · 行高 12
我的预约 / 短视频 / 导航 / 科普（下半屏，不动）
守护条 + 波浪（不动）
```

关键决策：
1. **主操作卡是唯一实心蓝按钮**。发送圆钮 72rpx，整条命中区 112rpx。
2. **四宫格 desc 从视觉层移除**，信息转 `aria-label`（不丢读屏语义）。这同时解决 H-3 的两行锯齿。
3. **四宫格统一为单色浅蓝底 + 正圆**（与常用服务的圆形素材同形），只保留图标本身的色相差异 → 解决 H-4 / H-5。
4. **banner 降级为 152rpx 说明条**：去掉独立按钮与手写标注（4 个 CTA → 1 个），保留医院插画但缩到 264×152（`aspectFill` 裁切，不裂图）。
5. 快选词由 `scroll-view scroll-x` 改为 `view` + `flex-wrap`（**WXML 一行改动，无 JS**），4 个词在 375px 上正好一行，小屏自动两行，不会露半个。

尺寸基线：页面边距 32rpx（与 `--space-page` 一致）；块间距 **24rpx**（现 20）；卡片内 24–32rpx。

### B-2 导诊页：首屏「能看懂」，开口后「只剩对话」

| 阶段 | 头部构成 | 目标高度 |
|---|---|---|
| 首次进入（`messages.length <= 1`） | 导航 84 + hero 200 + 就医人 88 + 完整进度卡 240 | ≈ 612rpx ≈ 306px（现 ≈870rpx） |
| 开始对话后 | 导航 84 + **紧凑条 64**（「AI 导诊 · 描述症状获取建议」）+ 就医人 88 + **进度单行 72** | ≈ 308rpx ≈ 154px |

- 实现方式：`wx:if="{{messages.length <= 1}}"` 切换 hero 与紧凑条；进度卡同理切换完整卡 / 单行条。**纯 WXML + 已有 data（`messages.length` / `progress`），零 JS 改动**。
- 底部固定区从 4 层压到 2 层：`ai-note`（一行 20rpx）+ `input-bar`（112rpx）。`collect-bar` 压到 64rpx 且仅在 `slotsText` 存在时出现（现状已 `wx:if`）；**`quick-services` 移入滚动区末尾**（DOM 移动，不改 `bindtap`）。
- 消息气泡统一：AI/用户均 `max-width:78%`、`padding:20rpx 24rpx`、`radius:24rpx`（贴边角 8rpx）、正文 26rpx/1.65。
- 结果卡 `tri-card`：主按钮「去挂号」满宽 88rpx；「院内路线 / 完整报告」降为第二行文字链（72rpx 触控），仍可点。
- 补问选项 `.ask-opt`：`min-height:80rpx`、26rpx 字、圆角 999 → 主要回答动作达标。

### B-3 报告页：先答「能不能等」，再给「去哪」，最后「怎么去」


## C. 统一设计规范（直接落 Token，不新建体系）

| 类别 | 规范 | 说明 |
|---|---|---|
| 品牌色 | `--primary #0B6EF8`、`--primary-dark #0A5AD8` | 只用于主按钮、选中态、关键强调 |
| 正文色 | `--text-main #00024E` / `--text-sub #5064A0` / `--text-weak #828CA0` | **不引入 #17223B**；弱文字只用于说明，不用于可读正文 |
| 底色 | 页 `--bg #F1F8FD`；卡 `#FFFFFF`；内嵌块 `--accent-soft #D7E9FA` 或 `--bg` | 内嵌块只用这两种，不再新增 |
| 语义色 | 红 `#F53F3F`/`#B42318`、橙 `--accent-amber`、绿 `--accent-green` | 红**只给急诊/危险**，不做装饰；本轮把导诊页硬编码红收敛到 `--accent-red` 派生值 |
| 图标底板 | **单一浅蓝 `--tile-blue`**，直径 72rpx，正圆 | 四宫格与常用服务同形；绿/琥珀/紫仅保留给「状态胶囊」，不作底板 |
| 字号 | title 36 / h2 30 / body 26 / caption 22 | 关键结论 40（科室名）；徽章 24；**禁止 20rpx 以下承载可读信息** |
| 字重 | 400 正文 / 500 次要 / 600 组件标题 / 700 页面标题 | 同屏最多两级字重对比 |
| 行高 | 标题 1.3 / 正文 1.6 / 长文 1.7 | 保持现有 |
| 间距 | 4·8·12·16·20·24·32·40；页面 32；块间 24；卡内 16–24 | 导诊页可用 24 页面边距（聊天页需要更宽）——这是**有理由的例外**，不是漏改 |
| 圆角 | 卡片 24 / 次级卡与按钮 20 / 内嵌块 12 / 胶囊 999 | 不变 |
| 阴影 | `--shadow-card`；主按钮**不加**投影（仅首页 FAB 保留一层） | 减少"浮起来"的块 |
| 按钮 | 主 88（`--btn-height`）/ 次 80 / 文字链 72；左右内边距 32 | `height` 改 `min-height`，xlarge 档不裁字 |
| 图标 | 24 / 32 / 44 / 56；图标与文字间距 8–12 | 沿用 `.ic-*` |
| 输入框 | 高 88（导诊 112 含容器），圆角 999，底 `--accent-soft`，占位色 `--text-weak` | 现占位 `#9CA3AF` 对比度不足，改 Token |
| 触控 | 主操作/表单 ≥88；次要 chip ≥64；**任何可点元素 ≥72** | 不机械套 88：胶囊类 chip 到 88 会挤掉一屏内容 |
| 大字档 | 固定高度一律 `min-height`；`calc()` 里的 rpx 走变量 | 现 `.input-field{height:80}`、`.tri-op{height:76}` 在 xlarge 会裁字 |

2. 所有可点元素可测高度：主操作 ≥88rpx，次要 ≥72rpx，chip ≥64rpx（开发者工具 Wxml 面板逐项量）。
