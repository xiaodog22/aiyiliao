# 登录页主视觉（小安）显示不完整 —— 定位与修复

> 2026-10-21 · 涉及 `home.xiaoan-robot`、V20 迁移、登录页取图链路
> 结论先说：**不是布局裁切，是素材 alpha 通道破损**；修复方式是把这张图改为**后端下发**，
> 包内保留同版兜底。

## 1. 现象

实机登录页右侧 3D 小安腰部以下"消失"，缺口边缘呈弧形锯齿，脚部与地面阴影不连续；
设计稿同一位置为完整机体。

## 2. 定位过程（证据链）

| 步骤 | 做法 | 结论 |
|---|---|---|
| ① 排除布局 | 读 `login.wxss#.lg-art`：`position:absolute; right:31rpx; bottom:-90rpx; width:21.3vh; height:27vh`，`mode="aspectFit"` | 容器只做等比缩放，不会在中段产生镂空；`overflow` 只裁底边 |
| ② 检查素材本身 | 手工解码 PNG（调色板 `colorType=3` + 256 项 `tRNS`），把 alpha 合成到品牌蓝背景 | **图本身就有缺口**，与实机截图缺口位置像素级吻合 |
| ③ 量化缺口 | 逐行统计 `alpha>200` 的左右边界 | 腰部 `y 528–578` 左缘从 248 突跳到 314（内凹 75px），另有被窄边包住的内部空洞 |
| ④ 对比旧统计 | 旧文件 alpha 分布：全透明 42.4% / 半透明 **45.79%** / 不透明仅 11.8% | 旧图不是"局部破损"，而是**整体被压成半透明**——蓝底透出后视觉上就是"消失" |
| ⑤ 查后端 | 服务端副本与包内文件 md5 相同；V16 登记为 `delivery='local'`，清单不下发 URL | 后端当时**没有**第二份可用素材，问题不可能靠"换来源"绕过 |

**判定：前端渲染无异常；后端资源本身是破损的同一份文件。** 修复必须换掉这份字节。

## 3. 为什么改走后端下发

素材要改，路径只有两条：

1. **改包内文件** → 每次改图都要重新提审发版，且这次修复本身就是在证明"图会出错"；
2. **后端下发**（本次选择）→ 清单声明 → 前端按 key 取图 → 出错只需替换服务端文件。

代价是首屏多一次网络请求，用两条机制抵消：

- **预热后换 src**：`wx.getImageInfo` 成功才 `setData`，避免 `<image>` 直改 src 的空白帧；
- **包内同版兜底**：`bundle_path` 指向同一张图，任何失败静默留在本地，不会出现白框。

## 7. 风险与回滚

| 风险 | 处置 |
|---|---|
| 真机未配 `downloadFile` 合法域名 → 取图失败 | `binderror` 自动回退包内同版图，页面不空白 |
| 隧道域名变更 | 清单 url 为空时用 `ENV.gateway` 拼；换域名只改 `config/env.js` |
| 换图后客户端仍显示旧图 | URL 带 `?v={sha256前12位}`，内容变即换 URL |
| 回滚 | 把 `delivery` 改回 `local`（新增一条迁移），前端 `resourceUrl` 自动退回包内路径 |
