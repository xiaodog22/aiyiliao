## 3. 下一阶段补齐用例（按优先级）

### 3.1 P2 · 网关异常路径（新增 pytest）

- 上游连接拒绝 / 5xx / 超时三态：断言网关快速失败、错误信封形状、不拖死连接。
- 断言点：`edge-gateway/tests/mock_business.py` 替身加故障注入开关（超时/500/拒连）。
- 验收：新用例全绿且不改动生产代码行为（若发现缺陷 → 进改进计划，不在测试任务里顺手修）。

### 3.2 P2 · voice-settings 设默认竞态回归（对应本轮新失败）

- 场景：远端目录响应迟到时，用户已先行「设默认」——断言**后到的 catalogRemote 不得覆盖用户刚写入的 wb_voice**。
- 手段：在 test-profile-deep-audit.js 断言①处增加受控时序（先挂起 GET /voices，触发 onSetDefault，再放行 GET），锁死「迟到的远端目录不回写 current」。
- 前置：先修复 voice-settings/voice.js 的复位逻辑（见改进计划 §2.1），测试随修复转绿后 `known:false`。

### 3.3 P3 · E2E 两条旅程（真机/开发者工具，手工脚本化清单）

1. 登录旅程：登录页（双身份）→ 患者一键进首页 → 杀进程冷启动 72h 免登录 → 退出登录撤销会话。
2. 就医旅程：首页症状快选 → 导诊结果卡 → 路线询问 → nav 路线 → 挂号全流程 → 记录页可见。
- 载体：docs/ 开发版真机验证记录模板，勾选制，附截图；不引自动化框架（脆弱度高，明确不做全量）。

### 3.4 P3 · miniprogram-simulate 组件测试（组件层）

- 只测自定义组件（skeleton / doctor-tab-bar）：属性渲染 + 事件触发。
- 页面级生命周期与 wx.request 不纳入（工具不支持，见测试体系文档 §2.1）。
