## 5. 「开发调试可用」≠「生产可用」——判断标准

| 场景 | 能证明什么 | 不能证明什么 |
|---|---|---|
| 开发者工具勾「不校验合法域名」 | 代码逻辑没写错 | 真机域名校验、TLS、证书链 |
| 开发版手机 + 手机端调试模式勾「不校验…」 | 真机上代码路径能跑通 | 体验版/正式版可用性（它们必校验） |
| `curl` 域名 200 | 链路与后端正确 | 小程序端域名配置、`<image>` 渲染 |
| `cli.bat preview` EXIT=0 | 编译器接受代码 | 运行时取图成功 |

**因此**：本项目当前所有"通过"结论，**上限就是「开发版 + 手机端调试模式」**。
任何写成"真机可用/线上可用"的表述，都必须以「关闭不校验 + 体验版或正式版」的实测为前提——目前没有。
