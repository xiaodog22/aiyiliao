## 0.5 基调定格工作流（Style Anchor）—— V1.1 新增，V1.2 已执行 Step 0/1

### 0.5.1 为什么要先定基调

本项目 2026-10-15 已生成 6 张图，但它们是**纯文字提示词驱动**的：模型对「极简扁平医疗风」的理解自由度极大，导致 ——
① 与项目真实视觉（`miniprogram/**` + `prototype-web/screenshots/`）存在偏差；② 各张之间的光影/材质/饱和度不统一；③ 想复用时无法说清「到底哪里不统一」。

**解法**：用用户认可的参考图，把抽象风格**固化成一张可复述的 Style Card**，之后所有图都以「参考图 + Style Card 语言」双约束生成 —— 风格漂移的自由度被压到最低。

## 5. 参数建议

### 5.1 基础参数

| 参数 | 建议值 | 说明 |
|---|---|---|
| 比例 / 尺寸 | **2:3** → `1024×1536` | 最接近手机截图 375:812（≈0.46）的可选尺寸 |
| 平板 / 横屏 | 3:2 → `1536×1024` | 对应 1194×834 / 812×375 |
| 投屏 | 16:9 → 用 `1536×1024` 后再裁，或让模型自行构图 | 1280×720 |
| 方图（图标/头像） | 1:1 → `1024×1024` | — |
| quality | `high` | 界面细节与文字可读性明显更好 |
| style | 不加风格词（用自然语言描述） | 加 `anime / 3D / cyberpunk` 会直接破坏扁平医疗风 |
| revise（豆包/混元） | `true`（首次）/ `false`（复现） | 复现时关掉改写 |
| 参考图强度（image-to-image） | **R1 高强度（贴近版式与气质）；R2 中强度（只取质感不取内容）** | 仅在需要「泛化新页面」时调低 |

### 5.2 中文文字的正确期待

- ✅ **能出**：4~8 字的界面短语（标题、按钮、标签），多数情况正确。
- ⚠️ **易错**：超过 10 字的正文段落、生僻字（「返酸」「候诊」「胶囊」）、数字与单位混排（`128/82 mmHg`）。
- 🔴 **必然出错**：小字号说明文字、列表内多行文案。
- **对策**：① 提示词里只写「关键短语」，正文用「一段浅灰说明文字」占位；② 出图后用真实截图替换文字区；③ 严禁把生成图直接当**医疗信息**传播（见 §8）。

### 5.3 素材类专用比值（避免返工）

| 素材 | 容器 | 素材比值要求 |
|---|---|---|
| 首页 banner 插画 | 520×300rpx | **1.732**（否则 `aspectFill` 裁切方向改变，楼被切） |

## 6. 一致性控制（跨图统一的四锚点）

| 锚点 | 做法 | 为什么重要 |
|---|---|---|
| **参考图锚点** | 每条提示词都带 R1 图生图输入；无 R1 可用时，用上一批已过「基调三问」的图替代 | **最高优先级**，压过一切文字描述；这是 V1.2 相对 V1.0 最大的变化 |
| **色板锚点** | 每条提示词都保留 `#0B6EF8` / `#F1F8FD` / `#00024E` / `#FFFFFF` 四个十六进制值 | 不写死色值，模型会漂到「医疗绿」「科技紫」 |
| **组件锚点** | 复用固定措辞：「淡蓝渐变 hero 卡」「pastel 圆角底板图标」「浅蓝胶囊 chip」「品牌蓝实心胶囊按钮 / 描边按钮」「软 3D 机器人吉祥物」「淡蓝波浪底」；构图固定「hero + 白卡纵向堆叠 + 底部 TabBar」 | 这几个名词在连续出图中形成稳定语汇，并防止模型自由发挥成 landing page / 桌面端 |
| **前缀/后缀锚点** | 前缀与后缀**一个字都不改**，只换中间的「页面主体」段 | 这是跨图风格一致的最有效手段 |

**迭代方法**：一次只改一个变量（页面主体 or 参考图），保留其余；满意的那张记下其 `seed` 与完整提示词，后续图以它为参考图续做。

## 8. 使用注意（红线）

1. **文字不可信**：生成图内的中文文案**不得作为需求/文案依据**；所有对外文案以 `miniprogram/**` 与 `utils/knowledge-kb.js` 为准。
2. **禁止用于医疗宣传**：本项目含真实分诊逻辑与红旗提示，**生成图不得包含任何医疗建议、剂量、诊断结论**，不得用于对外宣传物料（避免误导）。
3. **不得替代截图**：`prototype-web/screenshots/` 是「与代码同源」的忠实还原（由 `render-v4-prototypes.js` 生成）；生成图只作**风格参考**，不可用于验收取证。
4. **素材进包必须过体积门禁**：主包 1.19 MB / 上限 2 MB，新素材（视频、封面、大图）**一律进分包**；`packageContent` 现 252 KB。
5. **禁止 emoji**：与项目红线一致（emoji 跨设备字形不一致、色彩不可控）；生成图出现 emoji 应重出。
6. **水印**：部分模型（豆包/混元系）默认带角标水印，出图后必须裁除或参数化关闭。
