## 2. 明确：标准操作路径（唯一权威表）

> 用途：新人/评审/验收据此走查；任何新页面必须登记进本表，否则视为未完成。
> 字段：`入口 → 动作 → 立即反馈 → 失败兜底 → 返回路径`

### 2.1 患者主线（5 步走完一次就医）

| # | 页面 | 入口 | 动作 | 立即反馈 | 失败兜底 | 返回 |
|---|---|---|---|---|---|---|
| P1 | 账号登录 | 启动页 | 选「患者登录」→ 手机号 + 验证码 | 按钮 loading + 禁用防重复 | 提示 `errText(err)`，保留已填内容 | — |
| P2 | 首页 | Tab | ① 快选症状词 ② 输入症状 ③ 四宫格 ④ 服务宫格 | 各卡片按下态 | 未开通服务 → `NOT_READY` 提示中文说明，**不做假跳转** | Tab |

### 2.3 操作规范四条（全页统一）

| 规范 | 要求 |
|---|---|
| **反馈四件套** | 每个异步操作必须有：加载态 / 成功态 / 失败态 / 空态（与 03 评估的 `.state`、`.error-inline` 全局类一致） |
| **防重复提交** | 关键操作（登录、提交、预约、叫号）一律 `this._busy` 闸门 + 按钮禁用 |
| **适老** | 主操作 ≥112rpx；能用选的不用打字；每页回答「我在哪 / 该做什么 / 做完会怎样」 |
| **破坏性操作** | 清除缓存、删除、取消预约 → `wx.showModal` 二次确认，文案写清影响范围 |

## 4. 设置页参数与后端同步规划

### 4.1 目标模型：单一真源 + 本地优先

```
           ┌──── 内存（app.globalData.prefs）  ← 页面只读这里
           │
  storage（wb_prefs 快照，离线可用）  ←─→  后端 /api/v1/me/preferences（权威，登录后才存在）
```

| 原则 | 说明 |
|---|---|
| **本地优先** | 页面渲染只读内存快照，**永不因接口慢而卡顿或白屏** |
| **登录时拉取** | `onLaunch`/登录后 `GET` 一次，与本地做**三向合并**（本地 / 服务器 / 默认） |
| **变更时增量 PUT** | 只传变更字段；带 `updatedAt`，服务端做乐观并发 |
| **离线队列** | 未登录/离线 → 写 storage + 入队；恢复后回放（队列有上限，超出丢弃最旧） |
| **冲突裁决** | **以服务器 `updatedAt` 为准**；若本地 `updatedAt` 更新则本地胜并回写。绝不做"后写覆盖"的静默丢改 |
| **失败不阻断** | 同步失败 → 保留本地值 + 静默重试（指数退避），**不弹错误打扰用户** |

### 4.2 后端契约草案（新增，需合入契约后冻结）

| 方法 / 路径 | 用途 | 出参 |
|---|---|---|
| `GET /api/v1/me/preferences` | 拉取全量偏好 | `{ updatedAt, version, theme, fontScale, highContrast, voice:{voiceId,rate,readEnabled}, privacy:{remoteTriage}, pushEnabled }` |
| `PATCH /api/v1/me/preferences` | 局部更新 | 同上；`409` + `PREFERENCES_CONFLICT` 表示 `updatedAt` 过期 |

> 用 `PATCH` 而非 `PUT`，避免整包覆盖导致的字段互相擦除（与本轮 FO-11 的教训一致）。
> **强依赖**：本接口必须先有真实鉴权 —— **U-02（`CurrentUserContext` 匿名回退 `dev-user-1`）未闭环前，任何"用户偏好"都不具备语义**。

### 4.3 参数清单与归属（目标态）

| 参数 | 归属 | 持久化 | 同步后端 | 生效范围 |
|---|---|---|---|---|
| `theme`（standard/large/xlarge） | 用户 | ✅ | ✅ | 全局 |
| `fontScale` | 用户 | ✅ | ✅ | 全局（与 theme 合并为一套档位，避免两套口径） |
| `highContrast` | 用户 | ✅（FO-03 后） | ✅ | 全局根类 |
| `voice.voiceId` | 用户 | ✅ | ✅ | 音色页 |
| `voice.readEnabled` | 用户 | ✅ | ✅ | 问诊/导诊播报 |
| `voice.rate` | 用户 | ✅ | ✅ | TTS |
| `privacy.remoteTriage` | 用户 | ✅ | ✅ | 导诊是否走后端（项目已有 `useRemote:false` 隐私开关） |
| `pushEnabled` | 用户 | ✅ | ✅ | 通知 |
| 服务状态（健康角标） | 运行时 | 🔴 否 | 轮询 | 本页 |

### 4.4 存储键治理（统一前缀 + 白名单）

| 键 | 内容 | 清缓存时 |
|---|---|---|
| `wb_prefs` | 偏好快照（**收敛后唯一入口**） | 保留 |
