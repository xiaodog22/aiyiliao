### 2.1 患者端核心（8）

#### 01-首页 `患者端/01-首页.png`
- **功能**：问候；一句话症状输入（含麦克风 + 发送）；2×2 服务入口（AI 智能导诊 / 预约挂号 / 在线问诊 / 报告查询）；我的就医安排（空态 + 去预约挂号）；健康科普单卡。
- **数据**：问候语、患者名、最近预约（科室/医生/时间/地点）、科普卡片（标题/科室/阅读时长/标签）→ 后端。
- **跳转**：输入/麦克风/发送 → 导诊；4 宫格 → 对应页；查看全部 → 就医安排；去预约挂号 → 预约页；科普卡 → 详情。
- **接口**：`GET /api/v1/home/summary`（问候 + NEXT_APPOINTMENT）、科普列表。
- **素材**：右上角圆形医疗十字 AI 徽章（蓝色描边）、日历空态图标、科普封面插画（人+叶）。
- **当前实现**：✅ 有页面；⚠️ 4 宫格第 3 项被换成 **AI 养生**（设计为"在线问诊"）、第 1 项文案为"AI 智能问诊"（设计为"AI 智能导诊"）；⚠️ 额外多出"常用服务 8 宫格""健康提示短视频""智能导诊 banner""院内导航入口""全部科普入口""守护条 + 波浪"6 个设计稿没有的区块；⚠️ 科普卡用图标代替封面插画，且缺"科室 · 约 X 分钟"中的科室。
- **未实现功能**：在线问诊入口（页面本身也不存在）。

#### 02-AI智能导诊 `患者端/02-AI智能导诊.png`
- **功能**：聊天式导诊；AI 追问 + 单选问题卡（1-3天 / 4-7天 / 一周以上）；"根据您的描述，建议："三行建议（了解知识 / 查看科室 / 去预约）；免责说明；橙色 120 常驻条；底部语音 + 输入 + 发送。
- **数据**：AI 文本、选项、推荐科室、依据、号源提示、红旗判定。
- **跳转**：去看看 → 科普详情；查看科室 → 科室页；去预约 → 预约页；120 → 拨号。
- **接口**：`POST /api/v1/triage/recommendations`、`POST /api/v1/triage/emergency-checks`（均经网关兼容层 active，实测可用）。
- **素材**：标题右侧浅蓝圆角"对话+加号"图标；灯泡/医院/日历三枚建议图标。
- **当前实现**：✅ 有页面，含问题卡（`type:'ask'` 单选）、急诊卡、科室卡；⚠️ 建议区是"科室卡 + 挂号按钮"，没有设计的"知识 / 科室 / 预约"三行结构；⚠️ 顶部多了"对话/我的"Tab、用户信息条、就医进度卡、症状采集看板；⚠️ 导航栏无设计稿的电话图标。
- **未实现功能**：建议三行中的"建议进一步了解咳嗽相关健康知识 → 去看看"。

#### 03-预约挂号 `患者端/03-预约挂号.png`
- **功能**：搜索医院/院区/科室/医生；院区 + 科室下拉筛选；7 天日期横条（含"今天 18 / 周一 20"双行）；科室 chip 行；医生卡（姓名 + 职称胶囊 + 科室·院区 + 今日可约/约满 + 今日号源紧张）；底部"确认预约信息"半屏面板（就诊人 / 医院院区 / 科室医生 / 预约日期 / 就诊时段上午下午）。
- **数据**：院区、科室、医生、号源、患者/家庭成员。
- **跳转**：预约 → 打开底部面板 → 确认预约。
- **接口**：`GET /api/v1/departments`、`GET /api/v1/departments/{id}/doctors`、`GET /api/v1/doctors/{id}/slots`、`POST /api/v1/appointments`。
- **素材**：搜索图标、院区/科室下拉图标、医生默认头像（灰蓝人形）。
- **当前实现**：✅ 有页面，但是**4 步向导**（选科室 → 选医生 → 选日期/时段 → 确认），非设计稿的单页 + 底部面板；❌ 无搜索；❌ 无院区筛选（后端有 `hospitalId` 但无 `hospitals` 列表接口）；❌ 医生卡无"今日可约/约满"（`hasAvailableSlot` 已取到但 WXML 未渲染）；❌ 无"今日号源紧张"（后端只有布尔值）；❌ 无就诊人选择（`familyMemberId` 从未提交）。
- **数据契约**：`AppointmentCreateRequest` **已支持** `familyMemberId` / `contactPhone` / `symptomSummary`，是前端未用。

#### 04-在线问诊 `患者端/04-在线问诊.png`
- **功能**：医生信息卡（姓名/职称/科室/互联网医院 + "接诊中"绿点 + "医生正在查看您的描述"）；会话时间分隔"今天 9:30"；系统提示"问诊已开始，您可以描述症状或上传检查报告"；患者气泡 + "已发送 9:31"；**PDF 附件卡（检验报告.pdf / 已上传 · 2.3MB）**；医生"正在输入…"；"本次问诊"摘要卡（就诊事项 / 已传资料 1 份 / **问诊剩余 29 分钟** 橙色）；底部 + / 输入 / 语音 / 表情 / 发送。
- **数据**：医生在线态、消息流、附件、剩余时长、就诊事项。
- **接口需求**：医生会话绑定、消息收发、附件上传与下载、会话计时、已读/输入态。
- **素材**：医生头像、PDF 文件图标、语音/表情/加号图标。
- **当前实现**：❌ **完全缺失**。`app.json` 无此页面；后端无"医生-患者会话"模型（`consultations` 只有 `user_id`，无 `doctor_id`；`consultation_messages` 无附件字段、无已读态）；无附件上传接口（仅头像有 multipart）；无计时。现有 `pages/consultation` 是 **AI 对话 Tab**，与设计稿这页不是同一功能。
- **结论**：这是设计稿中**唯一整页缺失**的页面，也是唯一"零后端支撑"的医疗核心链路。

#### 05-健康档案 `患者端/05-健康档案.png`
- **功能**：顶部就诊人卡（头像/王女士/**本人**标签/"档案已同步 · 数据加密保护"/右箭头切换）；**5 分类图标宫格**（检验报告/检查报告/就诊记录/用药记录/诊断记录）；报告卡列表（标题 + 状态"已出结果"绿 / "待审核"橙 + 院区·科室 + 日期 + **查看报告**（描边）/**AI 解读**（浅蓝））；待审核项两个按钮置灰；底部"数据已加密存储…AI 解读结果仅供参考"。
- **数据**：就诊人、档案分类计数、报告元数据（标题/院区/科室/日期/状态）、报告内容、AI 解读结果。
- **接口需求**：`GET /api/v1/health-records`（现有）、报告详情、AI 解读、家庭就诊人切换（`familyMemberId`）。
- **素材**：5 枚分类图标（试管/影像/病历/药杯/诊断单）各配浅蓝底板；锁盾加密图标。
- **当前实现**：⚠️ 有页面但结构完全不同：横向分类 chip + 左侧时间轴卡片（类别徽章/标题/摘要/日期），**无就诊人卡、无 5 分类宫格、无报告卡、无查看报告/AI 解读、无加密声明条**。
- **后端差距**：契约 `category` 仅 6 值（VITALS/ALLERGY/MEDICATION/HISTORY/EXAM/OTHER），**无"检验报告/检查报告/就诊记录/诊断记录"**；`health_records` 无"报告状态"列；`attachments` 恒为 `[]`（`PatientService` 写死 `List.of()`，附件键只进幂等摘要、不落库）；无报告解读能力（AI 任务类型无 `REPORT_INTERPRET`）。

#### 06-我的就医安排 `患者端/06-我的就医安排.png`
- **功能**：三 Tab（全部① / 待就诊① / 已完成①，带计数）；待就诊卡（呼吸内科·门诊 / 陈医生·副主任医师 / 本院区·门诊楼3层 / 日历时间条 / **取消预约** + **查看详情**（青绿实心））；已完成卡（灰色时间条 / **查看报告** + **再次预约**）；底部"加载更多就医安排…"。
- **接口**：`GET /api/v1/appointments/me`、`POST /api/v1/appointments/{id}/cancel`（后端已有）、再次预约 → 预约页。
- **当前实现**：⚠️ 有页面（`profile/records`）：无三 Tab 与计数、无取消预约、无再次预约、无查看报告；"查看详情"是 `wx.showModal` 文本弹窗；卡片形态为"科室图标 + 科室 + 状态徽章 + 医生 + 院区·时间 + 预约号 + 查看详情"。
- **注**：设计稿 06 与 C06「挂号记录」是两页，但当前代码共用 1 页。

#### 07-个人中心 `患者端/07-个人中心.png`
- **功能**：淡蓝渐变 hero（头像 + 王女士 + "已登录 · 健康档案已同步" + 右上"就诊人管理 >"）；服务组 5 行（健康档案 / 我的预约 / 我的问诊（红点）/ 报告查询 / 就诊人管理）；通用组 3 行（消息通知 / 隐私设置 / 账号安全）；协议组 2 行（用户协议 / 隐私政策）；版本 1.0.0。
- **当前实现**：⚠️ 有页面但条目不同：hero 换成"白气泡标语 + 盾形水印 + 守护健康徽标"；服务组只有 3 行（挂号记录 / 健康档案 / 我的问诊）；账户组 3 行（个人信息设置 / 家庭成员管理 / 系统设置与关于）；**无就诊人管理、无报告查询、无消息通知、无隐私设置、无账号安全、无协议组、无版本号**；底部多了"退出登录 + 波浪"。
- **差距性质**：设计稿是"功能清单式"，当前是"卡片说明式"，信息架构不一致（P1）。

#### 08-适老化首页 `患者端/08-适老化首页.png`
- **功能**：大字号问候（28px）；症状输入（多行 + 发送 + **语音输入**并列大按钮）；2×2 大图标卡（AI 智能导诊 / 预约挂号 / 在线问诊 / 报告查询）；橙色"紧急情况请拨打120"大条；**3 项 TabBar（首页 / 就医 / 我的）**。
- **当前实现**：⚠️ 复用同一 `home` 页 + `theme-large/xlarge` 变量放大；❌ 无独立版式（设计稿的输入框+双按钮布局、大图标卡不同）；❌ TabBar 仍是 4 项（微信原生 tabBar 无法按主题切换）。
- **注**：设计稿自身与《设计规范说明》§4.5"患者端四项"矛盾，见第四节。
