# 05 · 前后端差距与风险清单（P0 / P1 / P2）

> 四类问题：**B** 后端 · **F** 前端 · **A** 素材 · **I** 联调
> 优先级：P0 阻断核心业务/鉴权/关键数据/核心流程不可用；P1 主要功能不完整或关键页不达设计预期；P2 一般功能/视觉细节/体验优化。
> 所有"证据"列均可直接定位复现。

## 五、明确"不做"的降级决策（防止为还原视觉而牺牲安全）

1. **不为了"在线问诊"外观而伪造医生在线态/剩余时间**。无真实会话就如实标注"暂未开通"。
