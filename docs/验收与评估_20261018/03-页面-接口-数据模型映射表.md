## 三、映射结论

> 计数口径：27 个唯一页面（图文详情与视频详情共用一个页面组件，合计 1 页；平板工作台与手机工作台同页，合计 1 页）。

| 统计 | 数量 | 页面 |
|---|---|---|
| 后端完整支撑（✅） | **9** | P02 导诊、P06/P14 挂号记录、P09 统一登录(dev)、P12 AI 问诊(后端)、P15 我的问诊、P17 个人信息、P19 音色、D03 挂号管理(后端) |
| 后端部分支撑（⚠️） | **15** | P01、P03、P05、P07、P08、P10、P11、P13、P16、P18、P22、P23、D01/D02、D04、D05 |
| 后端零支撑（❌） | **2** | P04 在线问诊、P20 投屏（无设备发现接口） |
| 纯前端静态（—） | **1** | P21 院内导航 |
| 合计 | **27** | |

| 其他统计 | 数量 |
|---|---|
| 前端整页缺失 | 1（P04） |
| 前端存在但取错接口/字段 | 3（D01/D02、D03、D04） |
| 前端存在但走已挂起旧路径 | 2（P13 care-plan、D03 叫号） |
| **后端有接口但前端未接** | **7**（`/doctor/appointments`、`/appointments/{id}/cancel`、`/appointments/stats`、`/consents/{p}/withdraw`、`/me/deletion-requests`、`/contents`、`/care-plans`） |

> 这 7 条"后端有、前端没接"是最便宜的修复面：**不需要新增后端能力，只改前端调用即可让 5 个页面功能成立**。
