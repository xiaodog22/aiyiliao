# 平板适配方案（待确认版）

> 状态：**待确认** —— 确认后才动代码。
> 依据：2026-09-14 第六十六批真机反馈（13.2" OPPO Pad 5 Pro）+ Chrome 无头盒模型实测。
> 结论先行：**推荐「B + C3」**；其余按需推进。

---

## 一、现状实测（为什么现在"不像平板应用"）

| # | 实测事实 | 影响 |
| --- | --- | --- |
| 1 | 全局只有一条 `900px` 断点：Token 缩放 + **所有页面限宽 720px 居中** | 对"单列卡片列表"页（首页/我的/记录）是对的；对**地图/画布/对话**类页面是浪费 |
| 2 | 导航页地图盒实测 **680×776**，而平面图是 1440×860（1.67:1）→ 只能显示 **680×406**，**盒子内 48% 是留白** | 平板最大的优势（大画布）完全没用上 |
| 3 | 页面里写死的 `rpx` 在平板上 ×1.6（1200pt 宽）| 导航页已修；其余页面多为流式布局，只剩头像/图标偏大（112rpx→179px），无致命问题 |
| 4 | 页面级平板断点：**17 个页面里只有导航页有** | 其余 16 页零适配 |
| 5 | 触控/字号：900px 档 body 15px、按钮 48px、行 ≥48px | 这部分是达标的，不用动 |

## 二、导航页（收益最大，先做）

### 方案 A：比例精修（保守 · 纯 CSS）
- 地图容器改 `aspect-ratio: 1440/860`（5:3），**消灭 48% 的上下留白**；
- 详情面板保持"就地占位 + 内容收缩"（第六十六批已实现）；
- 地图仍是 680 宽 → **地图面积不变，只是不空了**。

### 方案 B：突破限宽（推荐 · 纯 CSS）
- 仅导航页 override 720 限宽 → 内容列 1160；
- 地图 `aspect-ratio: 5:3` 占满宽 → **1160×693，平面图面积 ×2.9**；
- 详情面板保持"就地占位"（≤40vh、内容收缩、过长滚动）；分类 chips 与目的地条同宽（横向可见更多卡片）；
- 风险：低。纯 CSS；canvas 重测（`_relayout`）已有；标记文字在 0.8 缩放下仍约 13px（canvas 按屏幕字号绘制，不随缩放变小）。

| | 现状 | 方案 A | 方案 B |
| --- | --- | --- | --- |
| 平面图实际显示 | 680×406 | 680×406（无留白） | **1160×693** |
| 地图盒留白 | 48% | ≈0 | ≈0 |
| 改动 | — | 1 文件 ~20 行 | 1 文件 ~30 行 |
| 风险 | — | 极低 | 低 |

> 取舍说明：全局 720 限宽是给"单列卡片列表"定的（避免"手机界面放大"的空旷感）；
> 地图页是画布类页面，**限宽在这里等于把平板的钱花在留白上**，所以单独放开、并写明例外理由。

## 三、全站分级（确认导航页后再推进）

| 档 | 页面 | 处理 | 改动 |
| --- | --- | --- | --- |
| **C1 地图类（吃宽度）** | 院内导航 | = 方案 B | 纯 CSS · 0.5 天 |
| **C2 对话类（吃阅读比例）** | AI 问诊、AI 导诊 | 对话流限宽 720 居中（长句阅读比例），输入条与快捷服务行同宽；可选：右侧「就医进度 + 快捷服务」竖栏 | CSS 为主 · 1~2 天；竖栏需 WXML 包裹层 |
| **C3 列表类（吃密度）** | 首页、我的、挂号记录、健康档案、家庭成员 | 平板 2 列卡片网格（`flex wrap` + 卡片 50%），**不动 WXML** | 纯 CSS · 1 天 |
| **C4 医生端（信息密度）** | 工作台、挂号管理、床位 | 概览 + 列表左右双栏 | 需 WXML 包裹层 · 1~2 天 |

统一规则：内容列 ≤1160 · 两栏间距 24px · 触控 ≥48px · 字号沿用 900px 档（body 15px）。
横屏（1696 宽）：限宽页自动更宽仍居中 ✓；导航页全宽需给地图加 `max-height: 60vh` 防止过高（并入 B）。

## 四、验收标准（每条可测）

1. `node tools/preview-nav-page.js --measure`：平面图实际显示面积 ≥ 地图盒的 95%（留白 ≤5%）；6 项重叠检查全部 false；
2. 平板任意页面无横向滚动（`body scrollWidth == innerWidth`）；
3. 触控目标 ≥ 48px（抽查首页/我的/导航/问诊）；
4. 真机：地图标记文字可读、双指缩放不糊、旋转屏幕不拉伸（`_relayout` 生效）、大字档（large/xlarge）不破版。
