- **核心设计**：
  | 项 | 做法 | 理由 |
  |---|---|---|
  | 稳定 point id | `uuid5(固定命名空间, "{doc_id}::{chunk_id}")` | 与内容长度/运行次数/版本号无关 → 重复运行是**覆盖**不是新增 |
  | 切片 | 按 `sections[].h/p` 切；单节超 `--max-chars`（默认 400）按段落再切，**不跨节** | 片段自洽，检索命中后可整段返回 |
  | 元数据 | `source/doc_id/chunk_id/version/dept/scene/permission/ingested_at/section/content_hash/content_len` + 检索侧 `documentId/chunkId/content/title` | 一份 payload 同时满足审计与 `rag.py` 读取（它认 camelCase 或 `*_id`） |
  | 默认 dry-run | 不带 `--apply` 只打印计划 | 防误写 |
  | 远端保护 | Qdrant 非本机地址必须显式 `--allow-remote`，否则 exit=2 | 防误写生产 |
  | 重试 | embedding / upsert 均指数退避（默认 3 次）；单条失败只记账不中断，退出码 1 提示重跑 | 可重跑，不吞错 |
  | 旧版本清理 | 成功入库后按 `doc_id + version≠当前` 删除残留 | 版本升级不叠加 |
  | 回滚 | `--delete-version V [--delete-doc D] [--apply]` | 精确撤回某次入库 |
  | 日志脱敏 | 只打印 doc_id/chunk_id/字符数/维度/命中数，正文 ≤20 字预览 | 不落全文 |
