## 3. 一个设计决策：列表不下发 videoUrl

你的方案写「`toData`：有 video_key → signedVideoUrl」，没区分列表/详情。我按 `detail` 参数做了区分，理由：

1. 列表页没有播放器，用不到 URL；
2. 签名 URL 2 小时后必然过期，列表数据常被前端缓存（下拉保留、返回不重新拉），
   缓存里的 URL 过期后**点击进详情会直接 403**，比"没有"更糟；
3. 每条列表项多带 ~120 字节签名串，20 条就是 2.4KB。

实测确认：列表 2 条均不含 `videoUrl`。若你希望列表也带（例如显示时长角标），我可以改成列表也拼、但 TTL 缩短——告诉我即可。

## 6. `docs/dev-video-test-data.sql`（手工执行，不入 Flyway）

```sql
DELETE FROM health_articles WHERE id = 'dev-video-test';
INSERT INTO health_articles
    (id, title, summary, cover_key, category, type, read_min, published_at, sections_json, tip, related_json, video_key, status)
VALUES
    ('dev-video-test', '视频远端测试', '阶段三真机验证用：详情应返回签名 videoUrl', NULL,
     '日常防护', 'video', 2, NOW(3), NULL, '观看后请确认能播放、能拖动进度条。', NULL,
     'dddddddddddddddddddddddddddddddd.mp4', 'PUBLISHED');

DELETE FROM health_articles WHERE id = 'dev-video-none';
INSERT INTO health_articles (…, video_key, …) VALUES (…, NULL, …);
```

**与你给的示例有两点差异（必须说明）**：

1. **补齐了 `category` 与 `published_at`**：这两列是 `NOT NULL` 且无默认值，
   你给的 `INSERT (id, title, video_key, status)` 在 MySQL 上会报 `ERROR 1364 Field 'category' doesn't have a default value`。
2. **多插了一条 `dev-video-none`** 作为对照（验证"无视频时不渲染播放器"）。

**执行时有个坑**：Windows 的 `mysql` CLI 默认字符集不是 utf8mb4，直接 `<` 导入中文会报
`ERROR 1366 Incorrect string value`。必须加参数：

```bash
mysql --default-character-set=utf8mb4 -u wechar_dev -p wechar_dev < docs/dev-video-test-data.sql
```

前置：先把 mp4 复制成 `run/uploads/attachments/dddd….mp4`，否则详情能拿到 URL 但播放 404。
