## N1 · 拉取问诊会话消息正文（P0 · 契约缺口）

### 背景
`GET /api/v1/consultations` 的 description 已写明「返回元数据与摘要，不返回完整消息正文；正文按会话单独拉取」，但契约里**只有 `.../messages` 的 POST（发送）**，没有 GET（拉取）。这导致「在线问诊」页面重进后无法恢复历史消息，只能显示当次会话内容。

### 接口

```http
GET /api/v1/consultations/{consultationId}/messages
X-Request-Id: <uuid>
Authorization: Bearer <accessToken>
```

**路径参数**
- `consultationId` — string，≤64

**查询参数**（沿用全局规约）
- `cursor` — string，可选；不传 = 首页
- `limit` — integer，可选，默认 20

**响应 200**

```json
{
  "code": 200,
  "message": "ok",
  "data": [
    {
      "id": "m_01",
      "role": "user",
      "contentType": "TEXT",
      "content": "咳嗽三天了，有痰",
      "provenance": "USER_INPUT",
      "citations": [],
      "riskTags": [],
      "createdAt": "2026-10-19T09:00:00Z"
    },
    {
      "id": "m_02",
      "role": "system_notice",
      "contentType": "SAFETY_NOTICE",
      "content": "如出现呼吸困难、持续胸痛，请立即就医。",
      "provenance": "RULE_ENGINE",
      "createdAt": "2026-10-19T09:00:01Z"
    }
  ],
  "meta": { "nextCursor": null, "hasMore": false, "total": 2 }
}
```

- `data` 按 `createdAt` **升序**（先旧后新），便于客户端直接顺序渲染。
- `Message` schema 已存在（`role: user|assistant|system_notice`，`contentType: TEXT|VOICE_TRANSCRIPT|IMAGE_NOTE|SAFETY_NOTICE`），无需新增。

### 错误码

| 码 | 场景 |
|---|---|
| 401 | 未登录 / token 失效 |
| 404 | 会话不存在 **或** 越权（统一 404，不泄露存在性） |
| 503 | 依赖不可用 |

### 红线

- ⚠️ **越权一律 404**，不得返回 403（403 会泄露"存在但无权"）。
- 只返回**当前登录医生授权范围内**的会话。

## N2 · 报告 AI 解读（P1）

### 接口

```http
POST /api/v1/health-records/{recordId}/interpret
Content-Type: application/json
Idempotency-Key: <uuid>
X-Request-Id: <uuid>
Authorization: Bearer <accessToken>
```

**请求体** `InterpretationRequest`

```json
{ "scope": "SUMMARY" }
```

- `scope` — `SUMMARY`（通俗摘要）| `DETAIL`（逐指标详解），默认 `SUMMARY`；**未支持的 scope 返回 422**，不得静默降级为 SUMMARY。

**响应 200** `OkInterpretation` → `data` 为 `Interpretation`

```json
{
  "recordId": "hr_01",
  "status": "READY",
  "summary": "总体未见明显异常，两项指标轻度偏高，建议复查。",
  "sections": [
    { "title": "白细胞计数", "body": "略高于参考范围，常见于轻微炎症。", "abnormal": true }
  ],
  "disclaimer": "AI 解读结果仅供参考，不能替代医师诊断。",
  "generatedAt": "2026-10-19T09:00:05Z"
}
```

- `status=READY` — 有 `summary`（`sections` 可空，此时客户端显示「暂无可解读内容」）。
- `status=GENERATING` — 尚未生成完，客户端显示「解读生成中」并轮询/等待；**此处必须返回 200 而非 202 + 空 data**，让客户端能显示可见状态。
- `status=FAILED` — 生成失败，客户端显示重试入口。

### 错误码

| 码 | 场景 |
|---|---|
| 401 | 未登录 |
| 404 | 档案不存在 **或** 越权（含家庭成员未 GRANTED） |
| 422 | 报告尚未出具（`reportStatus` 非 `READY`）或不支持的 `scope` |
| 429 | 触发限流 |
| 503 | AI 上游不可用 |

### 红线（医疗合规）

- ⚠️ 解读结果**不得给出诊断结论、用药剂量或处方**。
- ⚠️ `disclaimer` 必须原样下发并由客户端原样展示，**不得截断或改写**。
- ⚠️ 幂等：同一 `Idempotency-Key` 重复请求返回首次结果，不重复计费、不重复生成。
- ⚠️ 敏感健康信息不进入埋点与日志正文（只记 operation / 耗时 / 异常类名）。

## N3 · 医生待处理事项（P1）

### 接口

```http
GET /api/v1/doctor/todos
X-Request-Id: <uuid>
Authorization: Bearer <accessToken>
```

### 响应 200 `OkTodoList`

```json
{
  "code": 200,
  "message": "ok",
  "data": [
    {
      "id": "todo_01",
      "kind": "CONSULT_REPLY",
      "title": "在线问诊待回复",
      "subtitle": "患者咨询等待医生处理",
      "count": 3,
      "route": "/pages/doctor/appointments/appointments?from=todo",
      "createdAt": "2026-10-19T08:30:00Z"
    }
  ]
}
```

- `kind` 枚举：`CONSULT_REPLY`（在线问诊待回复）· `CHECKIN_CONFIRM`（预约签到待确认）· `REPORT_REVIEW`（检查报告待审核）
- ⚠️ `route` **由服务端下发**（含所需参数），客户端不得自行拼业务路径；`route=null` 时该项不可点击
- ⚠️ 只返回服务端**可判定**的待办；空数组 = 确实没有待办，客户端显示空态，**不得伪造条目**

### 错误码

`401` 未登录 · `403` 非医生角色 · `503` 依赖不可用

## 通用规约（所有新接口统一遵守）

1. **信封**：`{ code, message, data }`，`code=200` 成功；`meta` 里放下页游标。
2. **幂等**：所有写操作（POST）必须校验 `Idempotency-Key`（8~128 字符），缺失返回 `400`。
3. **错误文案**：后端只下发**中文** `message`；前端走 `utils/err-text.js`，禁止直出英文/HTTP 码。
4. **状态不靠颜色单独表达**：每个状态必须同时有图标（或圆点）+ 文字。
5. **敏感信息**：患者姓名/手机号一律**服务端脱敏**后下发；`session_key` 等不入日志。
6. **超时**：AI 类接口沿用既有预算（ai 90s）；前端等待预算 180s。

## N8 · 医生账号登录（P0）

design 03-医生登录为「工号或手机号 + 登录验证」单输入框版式。现有契约 `WechatLoginRequest` 仅收微信 code，无账号密码/验证码端点。

```http
}
```

**响应 200**：`Envelope<SessionData>`（与微信登录同构）。
**错误**：400 参数缺失 · 401 验证码错误/过期 · 403 非医生角色 · 429 触发限流。

## N9 · 短信验证码发送（P1）

```http
POST /api/v1/auth/sms/send
Content-Type: application/json
Idempotency-Key: <uuid>

{ "phone": "13800001234", "scene": "DOCTOR_LOGIN" }
```

**响应 200**：`{ code:200, data:{ challengeId:"c_01", ttlSec:300 } }`。
红线：`challengeId` 一次性；同一手机号 60s 内不重复下发；生产环境短信网关由后端选型，前端不感知。

## N10 · 账号注销（P1）

design 10-系统设置底部红色「账号注销」入口。当前前端 `showModal` 显「待后端开放」。

```http
DELETE /api/v1/user/account
Authorization: Bearer <accessToken>
```

**响应 200**：`{ code:200, data:{ ok:true } }`。
**错误**：401 未登录 · 409 存在未完成预约/问诊（前端引导先处理）· 422 二次校验失败（需先验证码）。
红线：注销为不可逆操作，后端必须软删（30 天冷静期），不物理删库。

## N11 · 撤回授权同意（P2）

design 10-系统设置「撤回授权同意」入口。

```http

Content-Type: application/json
{ "scope": "PROFILE" }   // PROFILE / HEALTH_RECORDS / FAMILY
```

**响应 200**：`{ code:200, data:{ revoked:true } }`。
红线：撤回后对应数据后端停止处理，但已合法收集的数据不主动删除（合规要求）。
