## 已知边界（验证时注意）

1. **mask 未实现**：mao 部分带 mask 的 drawable 先忽略 → 个别部位可能叠层瑕疵，属 M1 内容
2. **纹理走后端下载**：首次进入需网络（2.6MB）；下载失败会自动用临时路径，仍失败则提示错误
3. **语音链路为 POC 演示**：录音→上行→本地话术回复（FunASR/LLM 编排在 M1）；本次只验证「帧上行 + 播放」两条通道
4. **真机需开启调试模式**（个人主体 + 无备案域名，无法配置合法域名）
5. ngrok 免费隧道长连接若被断：备选「真机 + 本机同 WiFi + 局域网 IP」调试

## 常见故障排查（2026-08-30 实测）

| 现象 | 根因 | 解决 |
| --- | --- | --- |
| 显示「数字人加载失败」 | ①纹理/TTS 用了 ws:// 协议（已修，改 http）②纹理缓存路径拼接错误（已修，改目录 mao_texture/0.png）③网关没起/连错端口 | 确认主应用（8000）在跑；模拟器用 ws://127.0.0.1:8000；真机用局域网 IP 或 ngrok→8000 |
| 后端日志 `WebSocket /ws/avatar 403/404` | 连到了未加载 avatar 模块的服务（旧实例未重启，或连错端口） | 重启主应用加载 avatar 路由；确认 env.js avatarWs 指向 8000；真机改局域网 IP |
| 真机连 127.0.0.1 失败 | 真机上 127.0.0.1 是手机自己 | env.js avatarWs 改 `ws://<电脑局域网IP>:8000`（手机与电脑同 WiFi） |
| 下载纹理失败 HTTP 404 | 静态目录未挂对 | 主应用已自动按 AVATAR_MAO_DIR（默认 wechar/mao）挂载 /static/mao，确认该目录存在 |

> 网关（随主应用 8000）已加握手日志：`[avatar] WS 握手来自 ... Origin=... UA=...`，下次报错可据此区分来源。
