## 二、代码规范（硬性执行）

### 2.1 技术栈
- **原生微信小程序**：WXML + WXSS + JS，**禁止** Vue/React/UniApp/Taro
- 所有页面必须注册在 `app.json` 的 `pages` 数组里
- 所有新资源（大图/视频）必须进分包，主包上限 2MB

### 2.2 API 调用规范
- **所有接口路径**必须定义在 `config/api.js`，禁止页面内硬编码 URL
- **所有请求**必须走 `services/request.js` 的封装（get/post/del/postForm/getBinary）
- **禁止**在代码里出现 `127.0.0.1` / `localhost` / `8001` / `8088`
- 唯一网关地址：`config/env.js` 的 `gateway`
- 响应格式：`{ code: 200, msg: "success", data: {...} }`
- 错误处理：统一 reject，页面用 `utils/err-text.js` 转中文文案

### 2.3 样式规范
- **颜色/圆角/阴影/字号** 全部走 `app.wxss` 的 CSS 变量（`--primary` / `--radius-lg` 等）
- **禁止**页面里硬编码颜色十六进制值（除非是渐变/特殊装饰）
- **禁止**用 emoji 做图标，必须用 `utils/icons.js` 的 PNG 图标
- 图标引用方式：`const icons = require('../../utils/icons.js')` → `this.setData({ icons })` → `<image src="{{icons.xxx}}" />`

### 2.4 页面结构规范
- 页面根节点：`<view class="page theme-{{theme}}">`
- 卡片：统一用 `.card` 类（白底/圆角32rpx/阴影/内边距32rpx）
- 按钮：`.btn .btn-primary` / `.btn-outline` / `.btn-ghost` / `.btn-mint`
- 区块标题：`.section-header`（带左侧浅蓝竖条）
- 列表行：`.li-row`（左图标底板 + 标题副标题 + 右箭头）

### 2.5 数据加载规范
- 页面加载顺序：骨架屏（skeleton 组件）→ 数据到达隐藏
- 后端不可用时：开发档 mock 降级 / 生产档错误态+重试按钮
- 长列表：用 `utils/paginate.js` 分页（`const { paginate } = require(...)` 对象导出）
