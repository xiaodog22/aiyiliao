## 5. 维护规则

1. 新增文档先放回 `docs/` 对应原目录，再在所属分类的 `00_清单.md` 补一行；不要只放进整理目录。
2. 文件改名/删除时，同步更新对应 `00_清单.md` 的链接与“原路径”；整理目录不代替原文。
3. 本目录不参与 `check-readme-links`（该门禁只查 `README.md` 与 `docs/INDEX.md`），但清单内链接应保持可点。
4. 私密手册、备份包只登记、不复制、不公开；`12_私密与备份` 仅作位置索引。
