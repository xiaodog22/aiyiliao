| # | 目标 | 衡量 |

## 2. 测试范围

**范围内**：
1. `utils/` 纯函数模块（datetime / err-text / apt-status / paginate / apt-date / triage-engine）；
2. `config/`（env.js 三档环境门禁 + api.js 路径表）；
3. `services/` 请求层（request.js / session.js 交互）；
4. 页面级运行时（home / consultation / doctor / profile 四长列表页 / packageNav 导航页）；
5. 资源端点链路（清单 → 网关 → 二进制，含 304 缓存）。

**范围外**：真实微信 API（wx.login/wx.request 真机行为，由真机验证记录覆盖）、
UI 视觉走查（效果图对齐文档）、ai-service 内部（后端测试文档覆盖）、第三方短信/OSS。
