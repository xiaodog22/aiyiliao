## 7. L6 端到端场景

必须逐条跑通并留存记录：

1. 未登录浏览科普 → 登录 → 返回原页面，状态保持。
2. 患者登录（微信 code + 手机号 code）→ 服务端返回角色 → 首页显示正确称呼。
3. 智能导诊：输入症状 → 命中红旗 → 立即显示急救提示（**断网条件下同样命中**）。
4. 智能导诊：正常症状 → 返回科室推荐 → 点击"去挂号"携带科室 ID。
5. 预约挂号：选科室 → 选医生 → 选时段 → 提交 → 成功页显示**服务端返回**的挂号单号。
6. 预约挂号：同一幂等键重复提交只生成一条记录。
7. 预约挂号：提交超时 → 通过幂等键查询 → 得到最终状态（不显示假成功）。
8. 挂号记录：只显示本人及已授权家庭成员数据。
9. 健康档案：上传文件 → 校验通过 → 可查看 → 删除需二次确认。
10. 家庭成员：添加成员 → 逐项勾选授权范围 → 解除关系后立即停止展示对方数据。
11. AI 问诊：发消息 → 阶段文案 → 完成 → 查看依据（**不出现思维链**）。
12. AI 问诊：请求处方/剂量 → 结构化拒答 + 就医引导。
13. 语音：录音 → 转写 → **用户确认文本** → 发送。
14. 语音播报：TTS 失败 → 保留文本 + 提示不可用，不播放占位音频。
15. 设置：撤回同意 → 相关采集入口立即关闭。
16. 设置：提交注销申请 → 显示处理时限 → 可撤销。
17. 医生工作台：仅显示本人号源统计与待办。
18. 挂号管理：状态流转成功/冲突分别处理，**无乐观更新残留**。
19. 床位管理：状态变更二次确认 → 成功后刷新；冲突有明确提示。
20. 院内导航：地图资源失败 → 自动降级为文字楼层与路线，导航不中断。
21. 大屏互动：全页无"已连接/已投屏"完成态暗示；顶部"规划中"提示常驻。
22. 全站断网：顶部离线提示；写操作置灰；恢复网络后由用户确认重试。
