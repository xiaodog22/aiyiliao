# 部署运维与低配优化（V4）

> 本文定义目标运维基线，不表示当前环境已经部署或达到相应 SLA。容量、延迟和准确率必须以目标硬件实测为准。

## 1. 目标拓扑

```text
微信小程序
  └─ HTTPS/WAF/反向代理
      └─ Spring Boot（业务权威、鉴权、审计）
          ├─ MySQL
          ├─ MinIO
          └─ FastAPI（内部 AI 编排）
              ├─ Redis
              ├─ Qdrant
              ├─ Ollama（0.5B 默认，7B 可选）
              ├─ qwen3-asr-0.6b（本地 ASR）
              └─ edge-tts（联网第三方，可关闭）
```

除反向代理和必要业务入口外，MySQL、MinIO 管理端、FastAPI、Redis、Qdrant、Ollama 均不直接暴露公网。生产、测试、开发环境隔离，凭据不复用。

## 2. 环境与配置

- 配置分为非秘密配置、密钥、模型/知识/提示版本清单；密钥由环境或密钥服务注入。
- 锁定容器镜像 digest、依赖版本、模型文件哈希、迁移版本；禁止生产使用浮动 `latest`。
- 生产关闭 debug、自动重载、示例数据和开放文档（若开放则强认证）。
- 时区、编码、对象桶、回调地址、超时、限流、保留期和功能开关均显式配置。
- 功能开关至少覆盖 RAG、ASR、TTS、7B 升级和高风险 AI 场景，可独立回滚。

## 3. 启动与依赖策略

### 3.1 不得阻断启动的资源

默认头像、图片、音效、数字人素材、示例知识、TTS 声音列表、ASR/7B 模型、缓存预热、非关键 Qdrant 集合缺失时，不得导致整个应用退出。应：

1. 使用本地内置占位或隐藏相关入口；
2. 在能力健康接口显示降级；
3. 后台有限重试并告警；
4. 所需任务快速返回明确错误；
5. 不在启动时联网下载未固定哈希的资源。

### 3.2 可阻断接流量的条件

数据库迁移不兼容、服务身份密钥缺失、关键配置无法安全解析、审计主账无法写入等可使业务服务就绪失败。存活探针仍应工作，便于诊断。

### 3.3 探针

- `liveness`：进程事件循环/线程可响应，不级联检查所有依赖。
- `readiness`：该实例能否承接核心业务；Spring Boot 通常依赖 MySQL，FastAPI 按能力细分。
- `startup`：给模型加载/迁移合理窗口，避免 liveness 反复重启。

## 4. 低配资源档

以下仅是配置思路，不是容量承诺：

### 4.1 最小业务档

优先保证登录、同意、档案、问卷、记录和文本接口。限制 Spring Boot 堆、数据库连接池、上传并发和分页大小；MinIO 使用生命周期与配额；日志异步且有磁盘上限。

### 4.2 AI 默认档（0.5B）

- 默认只加载 0.5B 模型，单/低并发队列。
- 限制上下文、最大输出和 RAG 候选数量。
- 模型进程空闲卸载策略需实测冷启动权衡。
- 结果使用内容寻址缓存；相同安全输入复用。
- ASR 与 LLM 避免同时抢占超限内存/GPU，可使用任务信号量。
- TTS 默认按需调用，失败退回文字。

### 4.3 7B 升级档

必须独立评估内存/显存、量化、上下文、并发、首 token 和总延迟。开启 7B 不代表所有任务都路由到 7B；按白名单任务和容量策略选择。资源不足时拒绝或排队，不应触发系统交换到不可用状态。

## 5. 低配优化优先级

1. **先限流与排队**：无界并发比模型本身更易压垮低配机。
2. **缩短上下文**：结构化历史摘要，引用必要轮次；不得丢失否定、药品、时间等关键语义。
3. **减少 RAG 候选**：先元数据过滤，再向量检索和轻量重排。
4. **内容寻址缓存**：键纳入模型、模板、策略、知识版本和租户隔离。
5. **流式改善感知**：只改善体验，不掩盖总超时；支持取消。
6. **媒体异步化**：ASR/TTS/上传使用任务和对象存储，避免占用 Web 工作线程。
7. **压缩与索引治理**：数据库按真实查询加索引；Qdrant 参数按数据规模实测。
8. **关闭非必要常驻资源**：数字人、高成本动画或 7B 用功能开关按需启用。

禁止通过移除安全检查、审计、引用验证或紧急医疗提示来换性能。

## 6. 容量与过载保护

定义每层预算：入口连接/请求体、Spring Boot 工作线程与连接池、AI 队列长度、各模型并发、上传并发、磁盘水位。达到阈值时返回 `429/503 + Retry-After` 或排队位置，不让请求堆积至 OOM。

任务优先级需谨慎：紧急医疗信号的即时静态提示不依赖模型队列；普通 TTS 可低于文本安全答复。禁止以付费等级压低医疗安全提示。

## 7. 超时、重试、熔断

- 客户端普通 API：体验预算约 8–12 秒；AI/媒体转异步。
- Spring Boot → FastAPI：连接和响应超时分开；创建任务短超时，执行不占连接。
- FastAPI → Ollama/Qdrant/edge-tts：各自超时与熔断池，避免级联。
- 重试只针对幂等操作；指数退避、随机抖动和上限。
- `edge-tts` 失败不重试到阻塞页面；文本立即可用。
- 熔断恢复使用少量探测，不同时放开全部流量。

## 8. 数据与备份

| 数据 | 备份策略 | 恢复验证 |
|---|---|---|
| MySQL | 加密全量 + 日志/增量（按 RPO 设计） | 定期还原到隔离环境、核对一致性 |
| MinIO | 版本/复制或备份；生命周期受保留策略控制 | 抽样恢复对象并核验 SHA-256 |
| Qdrant | 可由受控源重建，也可做快照 | 验证版本与知识清单一致 |
| Redis | 视用途决定持久化；不可作为唯一业务源 | 重启后任务可从主账恢复 |
| 模型/配置 | 清单、来源、许可证、哈希 | 离线按清单重建 |

备份同样是敏感数据，需加密、最小访问和到期销毁。删除请求要覆盖备份恢复后的再删除机制或明确合法例外。

## 9. 日志、指标与告警

### 9.1 日志

结构化字段：时间、级别、服务、环境、请求/任务 ID、路由、状态码、错误码、耗时分桶、版本。禁止记录令牌、密码、问卷答案、原始语音、完整对话、报告正文和签名 URL。堆栈只进受控日志。

### 9.2 指标

- 业务：登录/同意/提交/任务成功率，不包含敏感维度。
- 服务：吞吐、P50/P95/P99、错误、限流、线程/连接池。
- 数据：慢查询、复制/备份、对象错误、磁盘水位。
- AI：队列、冷启动、生成时延、缓存命中、空检索、安全拒答、ASR 实时率、TTS 失败。

### 9.3 告警

每条告警包含阈值依据、值班人、处置手册和静默策略。紧急：疑似越权/泄漏、数据库不可写、备份连续失败、磁盘将满；高：AI 队列失控、错误率激增；普通：非关键资源缺失、TTS 降级。

## 10. 发布与回滚

1. 发布前完成迁移兼容、备份恢复点和配置差异审查。
2. Spring Boot 先保持向后兼容；小程序发布后再清理旧字段。
3. FastAPI 模型、提示、策略、知识快照分别版本化；一次只改变可归因变量。
4. 灰度小流量，验证业务、医疗安全和资源指标。
5. 应用可镜像回滚；数据库优先向前修复或扩展/迁移/收缩模式。
6. AI 能力可通过开关独立回退到文本静态提示或 0.5B；不能回退到不安全旧策略。
7. 回滚后验证缓存版本隔离，防止新版本结果污染旧策略。

## 11. 故障演练

至少季度或重大变更前演练：

- MySQL 不可用/只读、连接池耗尽；
- MinIO 不可用、对象损坏、签名过期；
- Redis 数据清空、Qdrant 不可用；
- Ollama 模型缺失、0.5B OOM、7B 无法加载；
- `qwen3-asr-0.6b` 权重缺失或坏音频；
- `edge-tts` 断网、限流、声音移除；
- 默认资源/数字人素材全缺失但服务仍启动；
- 网络分区、DNS/TLS 证书问题、磁盘满；
- 备份恢复与用户删除请求重放。

记录实际恢复时间，不以“预计”代替。

## 12. 安全运维

- 管理端通过 VPN/堡垒机/受控网络访问，多因素认证。
- 容器以非 root 运行，只读根文件系统（可行时），挂载目录最小化。
- 数据库、对象存储、队列凭据分别授权并轮换。
- 镜像、依赖、模型和素材进行来源/许可证/恶意文件核验。
- 出口网络默认收紧；`edge-tts` 只允许必要目标，记录第三方调用状态但不记录文本。
- 应急响应定义隔离、密钥轮换、证据保存、用户/监管通知的人工决策链。

## 13. 手机、平板与弱网运维观测

前端按网络类型和设备档位仅上报非敏感性能分桶。重点关注手机/平板首屏、图片失败、键盘交互、横竖屏、超大字、弱网超时与离线恢复。资源 CDN/对象地址失败应有占位，不能阻断小程序启动；核心包控制体积，非关键页面分包/延迟加载需以真实构建验证。

## 14. 上线前容量报告应包含

硬件/系统、并发模型、数据规模、0.5B/7B 具体版本与量化、ASR 音频分布、RAG 集合规模、压测脚本和时间、P95/P99、错误率、峰值内存/显存/磁盘、过载行为、恢复时间、已知限制。没有实测数据时必须标记“待测”，不得填入推测数字。

## 15. 运维 No-Go

公网暴露内部数据/模型服务、无恢复验证、生产密钥入库、无界 AI 队列、磁盘无告警、敏感日志、资源缺失阻断全站、TTS 失败阻断文本、7B 未压测直接启用、无法关闭高风险 AI 能力，均为上线阻断项。
