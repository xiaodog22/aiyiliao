## 三、装饰与组件令牌

- `--hero-grad`：`linear-gradient(135deg,#DCE5F9,#B9C7EC)`（浅色 hero）
- `--section-bar`：`#B9C7EC`（区块标题竖条）
- `--wave-deep` `#B9C7EC` / `--wave-light` `#DCE5F9`（底部波浪）
- `--script-blue`：`#7E93C4`（手写体标语）
- `--shadow-card`：`0 20rpx 60rpx -28rpx rgba(70,86,150,.30)`
- `--tab-active`：`#7E93CC`（底栏选中文字，tab 图标是 PNG，不能跟主色变）
- `--tile-blue` `#E2E9F9` / `--tile-mint` `#DCEFE8` / `--tile-pink` `#F8E4ED` / `--tile-amber` `#F8EADB` / `--tile-purple` `#E8E4F7`（马卡龙五色图标底板）
- **恒定品牌渐变**：`--brand-grad-from` `#5F78C4` → `--brand-grad-to` `#8BA0DC`，**三档都不变**（超大字档把 primary 压黑，渐变若跟着变会出现「黑→蓝」脏渐变）

- 圆角：`--radius-lg` 32rpx（卡片）/ `--radius-md` 24rpx（图标底、输入框、信息条）/ `--radius-sm` 16rpx（状态标签）
- 动效：`--dur-fast` 140ms、`--dur-base` 280ms
- `--hero-title-boost` 8rpx（hero 大标题加码必须走变量，写死 `calc(… + 8rpx)` 会在宽屏被等比放大）

### xlarge 档的结构补偿（不是可选装饰，必须一起做）
- `--bg` → `#F7FAFF`（纯白会吞掉白卡边界）
- `--border` → `#7E8DA1`（原 `#E4E9F0` 在纯白上仅约 1.2:1，线等于消失）
- `--text-weak` → `#5A6478`、`--text-placeholder` → `#6F7C90`、`--section-bar` → `#5B8FC7`
- 细线加粗：`.divider` 2rpx、`.card` 描边 2rpx、`.row` 分隔线 2rpx

## 五、硬约束（写给模型的检查组）

1. **禁止跨端框架**：只能 WXML / WXSS / 原生 JS。
2. **图标**：只取 `utils/icons.js` 的键，`<image src="{{icons.xxx}}">`，深色底用 `*White` 版；**禁止 emoji 当图标**。
3. **文案**：后端错误码映射只走 `utils/err-text.js`；接口数据只走 `services/*`，页面不散写业务数据。
4. **触控热区**：≥88rpx（≈44px），适老档建议 ≥96rpx。
5. **对比度**：正文 ≥4.5:1，非文本边界线 ≥3:1。
6. **rpx 陷阱**：rpx 在 1200pt 平板上约放大 1.6 倍，凡用 rpx 写的宽/高/间距，**900px 与 600px 断点里都要用 px 重写一遍**。
7. 设计稿口径：1391px = 750rpx，逐项实测，不靠目测换算。
